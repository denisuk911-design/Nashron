# Training Management

Training in ROMAN2025 means knowledge-base learning and skill qualification. It does not mean model-weight training unless a real model-training pipeline exists.

## Training Types

Knowledge-base training:

- books;
- datasheets;
- application notes;
- reference designs;
- previous projects;
- lessons learned.

Skill qualification:

- practical tasks;
- tool exercises;
- review exercises;
- negative tests;
- reproducibility checks.

Employee evaluation:

- quiz;
- design exercise;
- review exercise;
- expected-answer comparison;
- retraining recommendation.

## Training Source Workflow

1. Select source files.
2. Select source type.
3. Enter title and authors.
4. Enter edition and year.
5. Enter source authority.
6. Enter copyright or usage status.
7. Calculate file hashes.
8. Select target roles/employees.
9. Select processing depth.
10. Preview learning queue.
11. Confirm import.

Imported material remains provisional until reviewed and activated by the owner.

## Training Program Fields

- program name;
- objective;
- assigned employees;
- required role;
- source materials;
- chapters or sections;
- expected knowledge domains;
- sequence;
- reviewer;
- qualification method;
- queue limits;
- pause conditions;
- owner checkpoints;
- completion criteria.
