# Professional Development

The intended learning loop is:

```text
source -> intake -> review -> knowledge card -> practice task
       -> artifact/evidence -> independent review -> skill update
       -> qualification decision -> next practice cycle
```

U1 stores `LearningSource` and runtime foundations only. It does not treat an
agent message as proof that a file was created or a skill was learned. Future
skill scores must use task results, artifact revisions, findings, reviews and
qualification tasks. Owner approval and independent review remain required for
high-impact qualification changes.
