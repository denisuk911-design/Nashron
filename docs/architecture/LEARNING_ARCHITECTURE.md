# Learning Architecture

`LearningSource` is the generic entry point for books, official documentation,
user instructions, project artifacts and approved external references. Each
source has type, location, processing state and trust metadata.

Source ingestion is not the same as learning. Later phases must create reviewed
knowledge cards, link them to skills, practice them in tasks and record evidence.
Unreviewed or conflicting material stays visible as draft/conflict data and
cannot silently alter a professional's qualification.
