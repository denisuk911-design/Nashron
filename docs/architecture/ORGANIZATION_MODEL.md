# Organization Model

An organization has a name, purpose, status, departments and members. Members
may be linked to an existing agent or remain unassigned in a template until the
owner provisions a real employee.

The organization layer answers: who belongs to which team, what profession and
position they have, and which workflow they use. Routing still uses direct
addressing, task relevance, workflow responsibility, handoff and team-call
rules. Membership alone must never make every employee answer every message.

The owner remains the authority for membership, permissions, approvals,
provider access and destructive actions.
