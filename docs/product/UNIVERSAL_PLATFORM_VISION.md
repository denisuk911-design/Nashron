# Team2050 Universal Platform Vision

Team2050 is a workspace for owner-managed AI organizations. Roman, Petr and
future employees are agents inside the product, not the product itself.

The permanent product contract is:

1. A user can create a profession, organization, team and workflow without Python.
2. Employees work from explicit tasks, roles, capabilities, tools and evidence.
3. Provider credentials are replaceable infrastructure, not employee identity.
4. Skills and knowledge grow through controlled sources, practice, review and evidence.
5. The owner sees what is designed, planned, running, verified and still unverified.

The core is domain-neutral. PCB/KiCad, software and culinary work are domain
packages that provide professions, skills, standards, tools and templates through
data. The core must not contain branches such as `if pcb` or `if culinary`.

U1 establishes the control-plane foundation. It does not claim autonomous
self-improvement, full BPMN, provider migration or qualification by prose alone.
Those require later evidence-backed phases.
