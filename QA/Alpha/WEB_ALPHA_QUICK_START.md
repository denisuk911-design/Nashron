# Luminifera Web Alpha

1. Распакуйте пакет в любую папку Windows.
2. Запустите `Luminifera.exe`.
3. Браузер автоматически откроет рабочее пространство `/app`.
4. Для остановки закройте окно launcher или нажмите `Ctrl+C` в консоли.

Профиль и база данных хранятся отдельно в пользовательском каталоге Team2050. Для чистого запуска используйте новый профиль Windows или задайте `TEAM2050_HOME` до старта. PySide `Team2050.exe` остаётся legacy fallback и для Web Alpha не требуется.
