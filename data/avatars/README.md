# Team2050 avatar library

The selectable library contains 92 local avatar images. The first set and the
three 24-image sets were generated specifically for Team2050; no celebrity
photos or known protected characters were requested or intentionally included.

The `avatar-sheet-*.png` files are generation contact sheets retained as source
material. Application code deliberately excludes them from employee selection.
The numbered `avatar-*.png` files are the selectable 256 x 256 assets.

Generated with OpenAI image generation on 2026-08-13. Use remains subject to the
applicable OpenAI terms and local law.
