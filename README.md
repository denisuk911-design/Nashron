# Team2050

Team2050 - настольный клиент для создания и управления командами AI-сотрудников. Пользователь выступает владельцем организации: создаёт команду из шаблона или вручную, назначает сотрудникам профессии, роли, ИИ-движки и права, а затем работает с ними в общем чате.

На чистой установке нет демонстрационных сотрудников и организаций. Существующая пользовательская база обновляется на месте с резервной копией перед известными автоматическими исправлениями.

## Возможности

- несколько изолированных организаций и разговоров;
- динамический состав команды без встроенных главных персонажей;
- Codex CLI и Gemini CLI через общий каталог провайдеров;
- роли, права, рабочие контексты, результаты и замечания;
- архивирование, восстановление и окончательное удаление сотрудников;
- проверяемый прогресс навыков по фактическим задачам и результатам;
- русский, украинский и английский интерфейс;
- светлые и тематические тёмные оформления;
- умная прокрутка, аватары и копирование выбранной переписки.

## Требования

- Windows 10 или Windows 11;
- Python 3.12+ для запуска из исходников;
- авторизованный поддерживаемый CLI для реальных ответов сотрудников;
- интернет-соединение для облачных ИИ-провайдеров.

Team2050 не запрашивает пароль от аккаунта провайдера. Авторизация выполняется официальным CLI, а секреты не сохраняются в обычной SQLite или JSON-конфигурации приложения.

## Запуск из исходников

```bat
scripts\run_windows.bat
```

Скрипт создаёт `.venv`, устанавливает зависимости и запускает приложение.

## Сборка Windows

```bat
scripts\build_windows.bat
```

Готовая сборка появляется в:

```text
dist\Team2050\Team2050.exe
```

## Пользовательские данные

Для совместимости с установленными версиями рабочий профиль пока хранится в:

```text
%LOCALAPPDATA%\Roman2050
```

В нём находятся база SQLite, настройки, локальная конфигурация сотрудников, аватары и технические логи. Это внутренний совместимый путь, а не название продукта. Для чистого запуска можно использовать `scripts\run_clean_windows.bat` либо переменную `ROMAN2050_HOME` с отдельной пустой папкой.

Перед ручным переносом или экспериментами закройте приложение и сохраните копию всей папки профиля.

## Проверка

```bat
.venv\Scripts\python.exe -m pytest -q
```

Ключевые регрессионные наборы дополнительно проверяют реальную legacy-схему, чистую установку, lifecycle сотрудников и организаций, маршрутизацию, провайдеры и chat UX.
